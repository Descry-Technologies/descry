# Code of Conduct

Descry Guard uses a simple standard: be direct, respectful, and focused on making the project better.

## Expected Behavior

- Treat contributors and users with respect.
- Assume good intent, but be precise about technical risk.
- Keep discussion tied to facts, reproducible behavior, and project goals.
- Accept maintainer decisions on scope, safety, and release timing.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing private security reports before coordinated disclosure.
- Posting secrets, customer data, private transcripts, or credentials.
- Repeated off-topic or bad-faith disruption.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; reject contributions; or block participants when needed to protect the project and its contributors.

Report conduct issues to conduct@descry.dev.
