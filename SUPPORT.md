# Support

Descry Guard is currently alpha software.

## Questions

Use GitHub Discussions once enabled for:

- installation help
- policy-writing questions
- adapter behavior questions
- demo feedback

## Bugs

Open a GitHub issue for reproducible bugs. Include:

- Descry version or commit SHA
- operating system
- agent host, if relevant
- command or hook payload shape
- expected and actual behavior

## Security Issues

Do not open a public issue for vulnerabilities. See [SECURITY.md](SECURITY.md).
